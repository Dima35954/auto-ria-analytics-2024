CarSalesAnalytic

Програмний комплекс для аналітики ринку продажу автомобілів. Проєкт створюється в рамках дипломної роботи бакалавра (Сумський державний університет).

Опис проєкту

Застосунок призначений для візуалізації та аналізу даних авторинку. Система обробляє масиви даних про продажі (бренд, ціна, рік випуску, технічні характеристики) та формує статистичні звіти, графіки динаміки цін, а також визначає тренди та рейтинги найпопулярніших моделей.

Технологічний стек

  • Framework: Flutter (Dart)
  • Архітектура: Layered Architecture (Data, Domain/Logic, UI)
  • Візуалізація даних: fl_chart
  • Тестування: flutter_test, mockito

Структура проєкту

Основна бізнес-логіка та візуальні компоненти знаходяться у директорії lib/. Дані обробляються модулем AnalyticsEngine, який інкапсулює математичні підрахунки та агрегацію масивів об'єктів CarListing.

Стандарти документування коду (Documentation Guidelines)

У цьому проєкті ми використовуємо вбудовані стандарти мови Dart для документування. Це дозволяє генерувати єдину базу знань за допомогою утиліти dartdoc.

  1. Що документувати: Усі публічні класи, методи, змінні, моделі даних та UI-віджети.
  2. Як документувати: Використовуйте потрійний слеш /// безпосередньо перед оголошенням елемента.
  3. Стиль: Перше речення має бути коротким і закінчуватися крапкою. Для посилань на інші параметри чи класи використовуйте квадратні дужки, наприклад: [CarListing].
  4. Контроль якості: Лінтер налаштовано на перевірку наявності документації (правило public_member_api_docs). Ваш код не пройде pre-commit хук, якщо публічні методи не задокументовані.
