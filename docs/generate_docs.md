# Інструкція з генерації документації

Для автоматичної генерації технічної документації у проєкті використовується стандартний інструмент **dartdoc**.

## Попередні вимоги
- Встановлений Flutter SDK (версія 3.x або вище).
- Налаштовані залежності проєкту (`flutter pub get`).

## Процес генерації
1. Відкрийте термінал у кореневій директорії проєкту.
2. Виконайте команду:
   ```bash
   dart doc .
