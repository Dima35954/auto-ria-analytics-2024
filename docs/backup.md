# Резервне копіювання (Backup)

Оскільки проєкт працює як статичний веб-додаток без підключеної бази даних, резервне копіювання стосується лише збереження стабільних збірок (білдів).

## Процедура бекапу
Перед кожним оновленням системи DevOps-інженер повинен заархівувати поточну робочу директорію:
`tar -czvf /backups/car_sales_backup_$(date +%F).tar.gz -C /var/www/html/car_sales .`

Архіви зберігаються на сервері протягом 30 днів для забезпечення можливості швидкого відкату.
