# Статичний аналіз коду (Linting)

## Обраний лінтер
У цьому проєкті використовується вбудований **Dart Analyzer** (через `flutter_lints`). 
**Причини вибору:** Це офіційний, найпотужніший і повністю інтегрований інструмент для мови Dart та фреймворку Flutter. Він забезпечує як перевірку стилю (linting), так і сувору статичну типізацію (static type checking) "з коробки", без необхідності встановлювати сторонні npm/python пакети.

## Базові правила
Налаштування зберігаються у файлі `analysis_options.yaml`. Ми використовуємо жорсткі правила для підтримки чистоти коду:
* `prefer_single_quotes`: Забезпечує єдиний стиль рядків (використання одинарних лапок).
* `prefer_const_constructors` та `prefer_const_declarations`: Покращують продуктивність застосунку (Performance), вимагаючи використання `const` де це можливо.
* `avoid_print`: Запобігає потраплянню відлагоджувальної інформації у production-код (Security/Clean Code).
* `curly_braces_in_flow_control_structures`: Обов'язкові фігурні дужки для `if`/`else` для уникнення логічних помилок.

Згенеровані файли (`*.g.dart`, `*.freezed.dart`) додано у винятки, оскільки вони не потребують ручної перевірки.

## Інструкція з запуску
Для перевірки коду виконайте команду в терміналі:
\`\`\`bash
flutter analyze
\`\`\`

## Звіт про виправлення проблем (75% та 89%)
Під час першого запуску лінтера у проєкті було виявлено **74 проблеми**.

* **Етап 50%:** За допомогою утиліти автоматичного виправлення `dart fix --apply` та ручного рефакторингу кількість проблем була зменшена до 15. Було виправлено 59 проблем (79.7%), що підтверджує досягнення показника у 50%.
* **Етап 90%:** Після додаткового ручного очищення коду (видалення невикористаних змінних, виправлення дублювання параметрів тем) залишилося лише **6 проблем** (усі стосуються `deprecated` методів, які залишені тимчасово). Загалом виправлено 68 із 74 проблем, що складає **91.8%** і підтверджує виконання вимоги у 90%.
